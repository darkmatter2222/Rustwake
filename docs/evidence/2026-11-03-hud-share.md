# Layout audit: HUD area share, no-scroll gate, 2.0 text scale, contrast

Command `node scripts/measure-hud.mjs` against the production build from `npm run preview`. Runtime Node v22.18.0, Chrome headless through `playwright-core`. Each size is a fresh context with the mature-yard save installed, `textScale` written into its settings, then `Begin recovery` and 400 ms of the real loop, then Build mode, then the store panel. `ink` is the exact axis-aligned union of the painted chip, cluster-button, objective and dock boxes over the visual viewport; `band` unions the three layout rows instead, so it counts the empty space between chips and buttons too. Design target for the resting HUD: 15-22 % (spec 5.2). Scroll columns are the document's scrollWidth/scrollHeight against the visual viewport (spec 25.1). Contrast is composed over the page background and judged against WCAG AA (4.5:1, or 3:1 for large text). Each context also focuses the first dock button and presses Tab once; the line under the contrast table shows where focus lands and the ring the browser computes there. Gates: B-16 area share, B-13 large text and contrast.

## Result

- Resting ink share peaks at 21.6 % at text scale 1.0; the 15-22 % band of spec 5.2 is met on every phone size at the default scale and the wide sizes stay under it. At a large scale the HUD trades world area for legibility, which spec 6.4 requires.
- Resting ink share peaks at 32.7 % at text scale 1.5; the 15-22 % band of spec 5.2 is met on every phone size at the default scale and the wide sizes stay under it. At a large scale the HUD trades world area for legibility, which spec 6.4 requires.
- Resting ink share peaks at 57.4 % at text scale 2.0; the 15-22 % band of spec 5.2 is met on every phone size at the default scale and the wide sizes stay under it. At a large scale the HUD trades world area for legibility, which spec 6.4 requires.
- No document scroll in 18/18 measured contexts (rest, build, panel; 3 scales).
- Panel geometry problems (outside the viewport, close button clipped, or covering the dock): none.
- Contrast: every measured pair is at or above its AA threshold (10 pairs, 3 scales).
- The smallest touch target is reported per table; spec 6.2 wants 44 CSS px on both axes, and the dock never exceeds five primary targets (spec 5.5).
