# HUD area share and no-scroll gate (B-16, spec 5.2 and 25.1)

Command `node scripts/measure-hud.mjs` against the production build from `npm run preview`. Runtime Node v22.18.0, Chrome headless through `playwright-core`. Each size is a fresh context with the mature-yard save installed and credits set, then `Begin recovery` and 400 ms of the real loop. `ink` is the exact axis-aligned union of the painted chip, cluster-button, objective and dock boxes over the visual viewport; `band` unions the three layout rows instead, so it counts the empty space between chips and buttons too. Design target for the resting HUD: 15-22 % (spec 5.2). Scroll columns are the document's scrollWidth/scrollHeight against the visual viewport (spec 25.1).

Result: the resting ink share runs 5.4 % to 22.1 % across the six sizes, and the no-scroll gate holds in 6/6 of them. Phone portrait lands in or beside the band; tablet and desktop sit under it because the world gains the extra area. Smallest dock target and smallest icon button stay at or above 44 CSS px (spec 6.2), and the dock never exceeds five primary targets (spec 5.5).
